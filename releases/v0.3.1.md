# v0.31
```diff
+ Discord authentication:
- replaced legacy account ID and API token login with Discord OAuth
- saves an opaque Aura token for 14 days and revokes it on logout
- shows the Discord identity, plan and data allowance inside Aura
- gates current and archived downloads behind the customer Discord role
- keeps source downloads exclusive to Standard members

+ Free trials:
- one-click free-trial panel with the Aura embed visual language
- new trials receive 7 days, 1 GB and the customer role
- staff can replenish trials, add or remove days and add data budget
- expired or exhausted accounts automatically lose the customer role

+ Standard Aura:
- one-command upgrade grants 30 days automatically
- AUD credits convert at A$2 per 30 days with 10% off for 3+ months
- expired Standard accounts automatically downgrade

+ Aura Discord bot:
- slash commands for accounts, budgets, days, trials and audit history
- signed HTTP interactions hosted continuously on Cloudflare Workers
- account changes are logged and mirrored to the configured Discord channel

+ Releases:
- immutable Windows, macOS and tracked-source archives for every version
- Aura Downloads puts the latest version above a divided older-release column
- automatic SHA-256 metadata and authenticated in-app updates
- tagged builds now validate and publish this changelog automatically
```
