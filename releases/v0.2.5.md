# v0.25
```diff
+ Encrypted UDP support:
- UDP-over-TCP v2 enabled across Romeo, Juliet and Mercutio
- VPN servers migrated from Caddy to sing-box Naive
- UDP-heavy apps, games and voice traffic now work through the tunnel
- transactional server migration with health checks and automatic rollback

+ Windows reliability:
- hardened elevated tunnel startup and shutdown
- validates sing-box config before launching
- verifies the VPN core survives startup and reports useful logs on failure
- only stops Aura's recorded sing-box process instead of every sing-box process
- fixed connecting hangs when Aura is already running as administrator
- ensures required sing-box dependencies are installed

+ macOS reliability:
- fixed detached sing-box launch
- restores executable permissions and removes quarantine on every launch
- fixed tunnel startup and DNS routing
- improved PID and log handling

+ Networking:
- switched TUN to the system stack with a safer 1400 MTU
- IPv4-only DNS strategy with reliable bootstrap routing
- safely escapes server credentials when generating JSON config
- added extra connection concurrency for Mercutio

+ Build and deployment:
- CI now validates the sing-box client config
- CI checks all PowerShell deployment scripts for syntax errors
```
