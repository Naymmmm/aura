# v26.2.0
```diff
+ Reliability:
- fixed the Windows helper updater failing with "Access is denied" when a running aura-core.exe still holds the install folder
- the installer now waits for every aura-core process to exit and retries the file swap before giving up
+ Budget enforcement:
- the Worker now records each account's monthly data usage server-side
- fresh server credentials are refused (403 budget_exceeded) once an account burns through its monthly budget
- the apps report usage deltas on heartbeat and show the real "budget used up" state instead of the wrong "expired"
+ Branding:
- refreshed the mac and Windows app icons to a frosted-glass lime squircle with the opaque asterisk
- the icon no longer ships as a flat opaque tile, so the desktop shows through
```
