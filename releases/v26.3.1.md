# v26.3.1
```diff
+ UDP, games and calls:
- each app socket now shares one encrypted UDP stream for every peer it talks to, instead of one stream per destination
- peers now see a consistent address for you, so peer-to-peer calls, games and WebRTC can connect directly instead of failing or relaying
- replies from peers you haven't messaged yet now reach your apps
+ Reliability:
- idle connections (SSH, chat, push and mail) are no longer cut off after 60 seconds of silence
- the tunnel uses larger TCP windows and buffers (up from 16 KB) so it is less likely to limit fast connections
+ App:
- the Aura window now floats instead of being tiled by tiling window managers like AeroSpace
- the app prompts you to update the helper to get these fixes
```
