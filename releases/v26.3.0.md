# v26.3.0
```diff
+ New desktop app:
- Aura is rebuilt from the ground up as a new native app for Windows, macOS and Linux
- Aura now lives in the menu bar / system tray: connect, disconnect and see status without opening the window
- new Settings page to install, update or remove the Aura helper
+ Rewritten tunnel engine:
- the background helper is rewritten in Rust and is about 5x smaller
- same servers and encrypted UDP-over-TCP transport, so games, calls and QUIC keep working
- the helper is updated from inside the app when a newer one ships
+ New platforms:
- native Windows on ARM build
- Linux build (AppImage and .deb)
- macOS build now runs on both Apple Silicon and Intel Macs
+ Compatibility:
- Aura now coexists with Tailscale and repairs a hijacked tailnet route on macOS
- fixed helper install failing on macOS even after entering the correct password
```
