# v26.0.1
```diff
+ Sign-in and network access:
- added a temporary remote Discord handoff for filtered networks
- restored legacy account ID and API token access behind More sign-in options
+ Connection control:
- added an explicit server picker and pin the chosen server until disconnect
- removed automatic server swapping during active connections
- enabled native IPv6 egress on every Aura server for dual-stack QUIC sites
+ Desktop experience:
- refreshed the compact desktop UI with clearer status and server controls
- replaced the old Arta artwork with Aura's Material asterisk across the app, tray, and app icons
- added searchable, severity-aware diagnostics with copy and clear actions
+ Updates and releases:
- adopted year.minor.hotfix versioning beginning with 26.0.1
- macOS now ships as a DMG and updates through a checksum-verified AppleScript installer
- the macOS updater fetches the latest build, relaunches Aura, and notifies when installation finishes
```
